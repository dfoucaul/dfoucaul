# Monochrome revision

The current profile uses GitHub's native font and a small monochrome portrait.
It has no banner lettering, language cards, public-only counters, or project table.
Previous design files are archived in this repository and are not displayed.

The activity total is read from the public GitHub contribution calendar, including
private contributions already included in that visible aggregate. It is labelled
as contributions, not commits. No names or content of private repositories are
queried or published. The scheduled workflow needs no personal access token.

## Portrait

Generated with the built-in `image_gen` tool from the original public avatar:
[`assets/medusa-monochrome.png`](../assets/medusa-monochrome.png).

Prompt:

Use case: style-transfer. Edit target: the attached exact original GitHub avatar showing Caravaggio's painted Medusa shield. Make a faithful monochrome halftone printing treatment of THIS IMAGE. Preserve the original artwork's exact geometry, original face, gaze, expression, snake shapes, round shield, ornament, light and dark structure. Do not redraw, modernize, stylize anatomy or alter the composition. Change only the rendering into very fine, restrained round-dot black-and-white halftone with a photographic print quality. Strict grayscale only: true black, white, neutral grays formed by fine ink dots. Absolutely no green, lime, yellow, beige, cream or any color cast. Clear face and snake details, tonal fidelity, subtle halftone dots, high enough detail that the painting remains instantly recognizable. Keep the original near-black square background and full round shield inside the image. Square artwork only, no text, no typography, no banner, no borders or marks added, no labels, no graphic decorations. The result should be quiet, faithful, elegant monochrome art, not a bold poster, not a logo, not a neon print. Source artwork treatment only, preserving identity and composition.
